# Environment setup

Run the commands below from the submission source root unless a command changes
directory. Keep the relative directory layout: `siamese_sl` imports shared
evaluation code from `sl_comparison` and benchmark helpers from
`SLMGAE-in-pytorch`.

## Local environment

Use a dedicated Python environment. The cluster workflow was developed with
Python 3.12; the included regression tests also pass with Python 3.9.6. No locked
dependency environment is supplied.

For training with existing embeddings, evaluation, and the regression tests:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch numpy scipy scikit-learn pandas tqdm requests networkx
```

Install a PyTorch build suitable for the intended CPU or GPU environment. The
optional packages below support robust PCA, external Excel data, and pytest:

```bash
python -m pip install robpy openpyxl pytest
```

`robpy` supplies ROBPCA for `--pca_method robust`. If it is unavailable or fitting
fails, the code falls back to median-centered SVD; that fallback does not perform
robust outlier filtering. `openpyxl` is needed to read the Gilbert `.xlsx` data.

Embedding generation needs additional packages, matching `slurm/reset_env.sh`:

```bash
python -m pip install fair-esm transformers huggingface-hub safetensors \
    sentencepiece sentence-transformers gensim obonet node2vec pykeen regex \
    "setuptools<81" charset-normalizer protobuf tiktoken mygene einops
```

Generation downloads pretrained models and source data and may require a GPU.
Some optional embedding methods have additional requirements: scPRINT needs a
checkpoint, and SeqVec needs `allennlp`. The current generation configuration and
embedding catalog are in `slurm/run_generate_embeddings.conf` and
`slurm/run_best_per_category.conf`. The scripts set `TRANSFORMERS_NO_TF=1` to
avoid loading TensorFlow through Transformers.

## Data and generated files

The package includes the pair data, source sidecars, gene mapping, baseline
support data, external-screen files, and shared folds at their existing paths:

- `data/SL_SynLethDB_experimental.txt` and
  `data/SL_SynLethDB_experimental_negatives.txt`, with both `.sources.tsv`
  sidecars for cell-line training.
- The gene universe at `data/gene_universe.txt` and shared folds under
  `sl_comparison/folds`, generated by `sl_comparison/prepare_folds.py`.
- The baseline support data and external-screen files specified by their
  respective configurations. External files retain the `external data` directory
  name, including its space.

Pretrained `data/all_genes_*.pt` embeddings, training checkpoints, downloaded
caches, and dense prediction matrices are excluded from version control.
Existing local embeddings and ignored caches may remain available. Generate or
supply any missing selected embeddings before training.

`download_synlethdb.py` prepares the pair files and sidecars.
`generate_all_genes_esm.py`, `generate_go_esm_embeddings.py`, and
`generate_embeddings.py` generate the embedding inputs; their SLURM wrapper is
`slurm/run_generate_embeddings.sh`. Use each script's `--help` for its input and
output options. The root benchmark orchestrator prepares folds before submitting
generation, so the pair files must already exist when it is launched.

Saved checkpoints are required for prediction, external fine-tuning, and the
post-hoc cell-line ablation. Train or supply them first. Reproducing the archived
ablation numbers specifically requires the original checkpoints and matching
embeddings; these are not included in this source package.

## Cluster setup

The SLURM scripts retain the original site's settings. Adapt `PYTHON_PATH` in
`siamese_sl/slurm/config.conf`, `VENV_DIR` in `siamese_sl/slurm/reset_env.sh`,
module commands, partitions, node constraints, and resource requests for the
target cluster. Also inspect the scripts under `sl_comparison/slurm`,
`SLGNN/slurm`, and `NSF4SL/slurm`. Use compatible Python installations on the
login and compute nodes.

After configuration, the environment setup command is:

```bash
cd siamese_sl
sbatch slurm/reset_env.sh
```

This script deletes and recreates its configured `VENV_DIR`, installs the
dependencies, and checks imports and CUDA. Use a dedicated environment path.
The root benchmark invokes this reset by default; pass `--skip-reset-env` when
using an environment that is already prepared.

Per-job `.conf` files control data generation, modality selection, ablation,
and external evaluation. See `slurm/README.md` for the workflow.

## Regression checks

From the source root:

```bash
python siamese_sl/tests/test_preprocessing.py
# Equivalent pytest invocation, when pytest is installed:
python -m pytest siamese_sl/tests -q
```

This source version contains 11 tests covering preprocessing, gene-order
alignment, label masks, held-out gene exclusion, and per-head checkpoint loading.
They use synthetic temporary inputs and do not require datasets or checkpoints.
The direct runner passed all 11 tests during source preparation;
the robust-PCA check used the SVD fallback because `robpy` was unavailable.

Once the cluster environment and baseline data are ready, submit the small GPU
training/evaluation check with `sbatch sl_comparison/slurm/preflight.sh`.
